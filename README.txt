ALBION ATLAS — FIRST WEBSITE VERSION

1. Unzip this folder.
2. To publish, create a free GitHub account at github.com.
3. Create a PUBLIC repository named albion-tools.
4. Choose Add file > Upload files. Upload index.html, style.css, app.js, and items.json from the unzipped folder (not the ZIP itself).
5. Commit changes.
6. In repository Settings > Pages, choose Deploy from a branch, main, / (root), then Save.
7. Your website will appear at https://YOURUSERNAME.github.io/albion-tools/ (deployment may take several minutes).

IMPORTANT:
- This is a starter prototype. Recipe names and material quantities were imported from your spreadsheet; some entries are incomplete or placeholders.
- Existing spreadsheet baseline RRR values: 36.7% without focus, 53.9% with focus. Daily and city bonus-specific combinations have NOT been supplied yet; choosing them currently keeps the baseline and shows a notice.
- No live market prices yet. Enter prices manually.
- Refining calculations are estimates based on spreadsheet tier material quantities; additional formula validation, inventory constraints, and item-specific city rules are pending.
- Open the deployed site to load items.json. Opening index.html directly from a local file may block JSON loading.

Generalist node planner: include node-data.js and general-node.js when uploading.
